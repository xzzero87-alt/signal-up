# 매매 플레이북 — 코인·주식 통용 원칙 (v1.0)

> 작성 2026-07-13. 근거: signal-up 검증 리셋(ADR-0027~0031)에서 얻은 실증 교훈.
> 자동매매 아님(ADR-0002). 알림 기반 수동 실행. 투자 조언이 아니며 본인 판단·책임.

## 0. 이 문서의 지위

- 프로그램 시그널(M2)과 **재량 매매 전부**에 적용되는 개인 규칙.
- 규칙 변경은 이 문서 개정으로만. 장중 즉흥 변경 금지.

## 1. 실증 근거 (이 프로젝트에서 직접 검증한 것)

| 사실 | 출처 |
|------|------|
| 타이밍 전략 6종 전부 게이트 미달 (국장 v1, 코인 v1/v3 포함) | ADR-0026·0028, 2026-07 재검증 |
| 엣지는 "언제 살까"가 아니라 "**무엇을 살까**"(횡단면 선택)에 있었다 | 검증 리셋 회고 |
| 12-1 횡단면 모멘텀(KR)만 이원 게이트 통과 | ADR-0030·0031 |
| 생존편향은 실제로 수익률을 왜곡한다 (+143% 환상 → PIT 유니버스로 수리) | Round 1 회고 |
| 채택 전략도 지수(KODEX200) 열위 구간이 존재한다 | OOS 2026H1 기록 |

**결론: 매수는 "선택" 규칙, 매도는 "리밸런스" 규칙. 타이밍 판단은 어느 쪽에도 넣지 않는다.**

## 2. 매수 규칙

1. **상대 모멘텀 상위만 산다.** 기준: 12-1 수익률(최근 1개월 제외 직전 12개월) 순위.
2. **유니버스는 사전 정의 + point-in-time.** 유동성(거래대금) 상위에서 뽑고, 그 시점에 알 수 있던 정보만 사용. 뉴스·추천·감으로 유니버스 밖 종목을 사지 않는다.
3. **동일가중 분산.** 주식 top10. 한 종목에 몰지 않는다.
4. **정해진 날에만 산다.** 월말 리밸런스일. "지금이 저점 같아서"는 매수 사유가 아니다 — 타이밍 전략 6종이 전부 실패했다.

## 3. 매도 규칙

1. **매도 = 리밸런스 교체가 유일한 경로.** 월 1회, 모멘텀 순위에서 밀린 종목을 기계적으로 편출.
2. **재량 손절·익절 금지.** "많이 올랐으니 익절", "무서우니 손절"은 타이밍 전략의 변형이며, 타이밍에는 검증된 엣지가 없다.
3. **구조적 예외만 즉시 매도:** 상장폐지 사유·거래정지·감사의견 거절 등 규칙이 전제한 시장 구조 자체가 깨진 경우.
4. **하락장에서도 규칙 유지.** MDD −35%는 사전에 공시된 비용이다. 견딜 수 없으면 §5의 금액을 줄이는 것이지 규칙을 바꾸는 게 아니다.

## 4. 자산군별 적용

| | 국내주식 | 코인 |
|---|---|---|
| 검증 상태 | **게이트 통과** (ADR-0030) | **미검증** — 엣지 원점 (ADR-0028) |
| 실행 | M2 알림대로 top10 리밸런스 | 신규 진입 보류. 재도전은 PIT 모멘텀을 동일 게이트에 통과시킨 뒤 |
| 허용 비중 | 주 배정 자금 | 게이트 통과 전 0 (연구·페이퍼만) |

코인도 원칙은 동일하게 적용하되, **검증 통과 전에는 실탄을 넣지 않는다** — 이것이 엣지-우선 규율(ADR-0017/0022)의 통용 버전.

## 5. 자금·리스크

1. 투입 금액 = **−35% 평가손을 견디고 규칙을 유지할 수 있는 금액**. 그 이상은 넣지 않는다.
2. 레버리지·신용·미수 금지.
3. 물타기 금지 (리밸런스 외 추가 매수는 타이밍 베팅이다).
4. 생활비·단기 필요 자금 투입 금지.

## 6. 금지 목록 (하지 않는 것)

- 장중 호가창 보고 진입/청산
- 뉴스·커뮤니티발 종목 매수
- 리밸런스일 외 임의 매매
- 검증 안 된 전략에 실탄 (백테스트 게이트 통과가 유일한 입장권)
- 규칙이 틀린 것 같을 때 즉석 수정 — 의심되면 기록해 두고, 데이터로 재검증한 뒤 문서 개정

## 7. 개정 절차

1. 변경 제안을 근거 데이터와 함께 기록
2. 백테스트/재검증으로 게이트(ADR-0029) 확인
3. 이 문서 버전 업 + 변경 이력 기재
