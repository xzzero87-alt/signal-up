# ADR-0031: M2 라이브 채택 — 월말 리밸런스 알림 제품 (국장 알림 재개)

**Date**: 2026-07-10
**Status**: accepted
**Deciders**: xzzero87

## Context

ADR-0030의 필수 검증 3건이 완료됐다(commit 2eff3b9): (a) 독립 재현 0.0%p 오차, (b) 미수집 5종 중 4종 보강 후 마진 확대(IS +245.2% vs 벤치 +72.8%, 샤프 1.10 vs 0.77 / OOS 2026H1 +76.4% vs +27.2%, 샤프 2.04 vs 1.21), (c) KODEX200 대비 — IS 우위(+245.2% vs +81.3%), OOS 열위(+76.4% vs +93.0%, 초대형주 쏠림장) 투명 기록. 사용자 결정으로 제품 형태 A(월말 리밸런스 알림 미니멀)를 채택한다. ADR-0026/0028의 라이브 재기동 금지 조건("게이트 통과 전략 확보")이 충족됐다.

## Decision

1. **M2(12-1 횡단면 모멘텀, top10 동일가중, 월간 리밸런스)를 국장 라이브 전략으로 채택한다.** 기존 봉단위 국장 v1 알림은 계속 중단 상태를 유지하며, 국장 알림 재개는 본 월간 알림으로만 한다.
2. **제품 형태 = 월말 리밸런스 알림**: 매월 마지막 거래일 마감 후 텔레그램 1회 발송 — top10 목록(순위·종목·12-1 모멘텀·종가) + 전월 대비 편입/편출 diff + 다음 리밸런스 예정일. 알림 전용(자동매매 없음, ADR-0002 불변).
3. **운영 파라미터 고정**: 유니버스 = 전년 12월 일평균 거래대금 top50(풀 = `scripts/round2_pool.csv`), 시그널 = 12-1 모멘텀(252-21 거래일), top10 동일가중, 매월 마지막 거래일 마감 기준. **파라미터 변경은 게이트 재통과 없이는 금지.**
4. **유니버스·풀 유지보수**: 유니버스는 매년 1월 첫 리밸런스 전 자동 갱신. 후보 풀은 연 1회(12월) 신규 대형주 수동 검토로 보강 — 풀 편향 재발 방지 절차.
5. **아키텍처**: 기존 봉단위 루프·Strategy Protocol과 독립된 신규 월간 모듈(`momentum/`)로 구현. DESIGN.md §8.1~8.5 시그니처 불변(하드라인). 기본 비활성(`momentum_enabled=false`) — 라이브 점화는 구현·테스트 완료 후 사용자가 설정으로.
6. **공시 의무**: 초대형주 쏠림장에서 시총가중 지수 열위 가능(OOS 실측)을 GUI/문서에 명시.

## Alternatives Considered

### Alternative 1: B안 (A + 월중 급락 경보)
- **Why not**: 유용하나 스코프 확대. 미니멀 v1 안정화 후 다음 반복에서 재검토(기각 아님).

### Alternative 2: C안 (페이퍼 트래킹 1~2개월 후 채택)
- **Why not**: 봉인 OOS 통과 + 독립 재현까지 마친 상태에서 과잉 신중. 월 1회 알림이라 라이브 리스크도 제한적.

## Consequences

### Positive
- 약 정지 상태였던 제품에 게이트 통과 전략 기반 알림이 재개됨.
- 월간 잡은 봉단위 루프 대비 운영 부담·장애 표면적이 작음.

### Negative
- 신규 모듈(유니버스 계산·월말 판정·상태 영속화·알림 포맷) 구현 필요.
- 월 1회 알림은 제품 체감 빈도가 낮음 — 사용자 기대 관리 필요.

### Risks
- MDD −35% 프로필 — 알림을 따르는 사용자의 고통 한도 확인 필요. Track 2(방어) 결합은 후속 탐색.
- 12월 거래대금 유니버스에 과열 테마주 유입 가능 — 사실적 특성으로 수용, 유니버스 공개로 투명화.
