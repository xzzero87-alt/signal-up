# ADR-0030: 횡단면 모멘텀 M2(12-1 top10) — point-in-time 재검증 게이트 통과, 정식 채택 절차 개시

**Date**: 2026-07-10
**Status**: accepted
**Deciders**: xzzero87

## Context

ADR-0029 Decision 2의 통과 전제(point-in-time 유니버스 재검증)를 이행했다. KRX 로그인 제약으로 시총 대신 **거래대금 프록시**(2안, 사용자 승인)를 사용: 후보 풀 145종(현 대형 + 몰락 대형주·테마주 수동 보강, KIS로 101종 신규 수집) → 연도별 유니버스 = 전년 12월 일평균 거래대금 상위 50. 몰락주(위메이드·카카오뱅크·SK바이오사이언스·에코프로머티 등)가 실제 유니버스에 포함되어 생존편향이 실질 통제됨.

**결과** (`reports/compare/round2/round2_results.csv`):
- 인샘플(2022-03~2025-12, 비용 0.3%): 누적 **+171.9% vs PIT-EW50 벤치 +54.1%**, 샤프 0.94 vs 0.63, 4/4년 벤치 이상, MDD −36.1% vs −28.6%.
- **봉인 OOS 1회 개봉**(2026-01~07-08, 사전 선언 파이널리스트 M2·비용 0.3%): 누적 **+59.6% vs 벤치 +25.4%**, 샤프 1.75 vs 1.14. 보유 종목은 2026 실제 주도 섹터(AI반도체·방산·조선·전력기기)와 정합.

## Decision

1. **M2(12-1 횡단면 모멘텀, top10 동일가중, 월간 리밸런스)를 Track 1 게이트 통과로 판정**하고 정식 채택 절차를 개시한다.
2. 정식 채택 전 **필수 검증 3건** (Cowork 스크리닝 → 사용자 환경 정식 확인):
   (a) 사용자 환경에서 독립 재현(CLI/스크립트 패리티),
   (b) 미수집 5종(SK스퀘어·한화에어로스페이스·HD한국조선해양·LIG넥스원·HD현대미포)을 상장일 기준 재페치해 포함 재실행 — 현재는 이들 부재가 보수적 방향(랠리 주도주 제외)으로 작용했을 것으로 추정되나 실측 필요,
   (c) **시총가중 지수(KOSPI/KOSPI200) 대비 비교 추가** — 벤치는 ADR-0022 관례(유니버스 EW B&H)를 따랐으나, 2026H1처럼 초대형주 주도 장세에선 시총가중 지수가 EW보다 훨씬 높음. 제품의 정직성을 위해 두 벤치 모두 보고.
3. **제품 형태 결정 필요** (채택 시): M2는 봉단위 시그널이 아니라 **월말 리밸런스 알림**(top10 목록 + 편입/편출 diff) — 기존 Strategy Protocol과 다른 실행 형태이므로 구현 스펙과 함께 별도 결정.
4. 모든 결과의 원자료·재현 스크립트는 `reports/compare/round2/`에 보존한다.

## Alternatives Considered

### Alternative 1: 현 결과로 즉시 라이브 채택
- **Why not**: ADR-0024의 교훈 — 단일 환경 백테스트 근거로 라이브 금지. 독립 재현 + 미수집 종목 보강 + 지수 대비 비교가 남음.

### Alternative 2: 시총 기준 유니버스로 재검증될 때까지 보류
- **Why not**: 거래대금 프록시는 ADR-0029에 명시된 승인된 차선책이고, 몰락주 포함이라는 핵심 통제를 달성함. KRX 계정 확보 시 시총 기준 교차 검증은 보강 항목으로 남김(기각 아님).

## Consequences

### Positive
- 6종 전멸 이후 처음으로 **게이트를 정면 통과한 전략** 확보 — "선택(모멘텀)" 축 전환이 유효했음이 데이터로 확인.
- OOS 규율(봉인→사전 선언→1회 개봉)이 실제로 작동한 첫 사례.

### Negative
- 월간 리밸런스 알림은 기존 아키텍처(봉 마감 평가 루프)와 달라 구현 작업이 필요.
- 거래대금 유니버스는 12월 과열 테마주가 유입될 수 있음(2024 유니버스의 에코프로머티·두산로보틱스 등) — 사실적이지만 변동성 원천.

### Risks
- MDD −36%는 벤치(−29%)보다 깊음 — "최대 수익" 목표와 정합하나 사용자 고통 한도 확인 필요. Track 2(방어) 결합은 후속 탐색 항목.
- 2026H1 같은 초대형주 쏠림 장세에서 시총가중 지수 대비 열위 가능(검증 2c에서 실측).
