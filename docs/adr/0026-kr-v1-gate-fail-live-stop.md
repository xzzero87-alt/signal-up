# ADR-0026: 국장 일봉 v1 게이트 미달 확정 — 라이브 중단 + 재설계 (ADR-0024 supersede)

**Date**: 2026-07-08
**Status**: accepted
**Deciders**: xzzero87

## Context

ADR-0025 Decision 2의 후속 진단(2×2 분해: max-hold {10,24} × 웜업 {0,320일}, 43종, 인프로세스 드라이버 양방향 패리티 검증)으로 ADR-0024와 ADR-0025의 F0 수치 불일치 원인이 확정됐다. 원인은 두 버그의 조합: (H1) `kr_strategy_matrix.ps1`의 `$MaxHold=10` 하드코딩이 kr_fractal용에서 v1 실행에 잘못 상속된 회귀(기여 ~60%), (H2) 웜업 부재(기여 ~40%, ADR-0025에서 수정됨). 데이터 변경(H3)은 종목별 B&H 43/43 일치로 기각.

핵심 결과 — H1을 배제한 **정정 기준선(max-hold 24 + 웜업 320일)도 게이트 미달**: 누적 중앙값 **+19.41% < B&H +23.61%** (샤프 0.45, 거래 771, 강건성 3/4은 충족). ADR-0024의 통과 판정(+25.8%)은 웜업 버그로 부풀려진 결과였고, 원래 통과 마진(+2.2%p)이 얇아 H2 단독으로도 뒤집혔다.

## Decision

1. **국장 일봉 v1(BB+CCI)의 ADR-0022 게이트 판정을 "미통과"로 확정**하고 ADR-0024를 supersede한다. 정정 기준선(웜업 320일, max-hold 24)이 이후 모든 KR 백테스트의 표준 조건이다.
2. **라이브 국장 알림을 중단한다** (`kr_enabled=false`). 엣지-우선 규율(ADR-0017/0022)의 일관 적용: 게이트 미달 전략은 라이브 금지. 재개는 어떤 전략이든 정정 조건의 게이트를 통과한 뒤에만.
3. **국장 전략 재설계에 착수한다** (별도 세션·별도 스펙). 유의: 기존 probe 결과(v4 Donchian, kr_fractal 등)도 웜업 버그가 있는 조건에서 측정된 것이므로, 재설계 후보 비교는 전부 정정 조건으로 재실행해야 한다.
4. **재발 방지**: `kr_strategy_matrix.ps1`의 `$MaxHold` 하드코딩을 파라미터화(기본값 = 엔진 기본 24)하고, 웜업을 기본 적용한다.

## Alternatives Considered

### Alternative 1: 라이브 한시 유지 + 재설계 병행
- **Pros**: 알림 전용·자동매매 없음·방어 프로필(샤프 0.45, 3/4년 양수)이라 실해 위험 낮음. 재설계 기간 국장 알림 공백 없음.
- **Why not**: 미검증 시그널을 계속 신뢰 대상으로 두는 것 자체가 규율 훼손. 사용자 결정으로 규율 일관 적용 선택.

### Alternative 2: 게이트 기준 재검토 (위험조정/노출조정 기준 신설)
- **Pros**: "누적>B&H"는 절대수익 기준이라 방어형 전략에 구조적으로 불리(2025 강세년이 B&H를 지배).
- **Why not**: 미달 확인 직후의 기준 변경은 확증편향 위험. ADR-0024 Alt 3에 이어 재차 기각. 기준 논의가 필요하면 결과와 무관한 시점에 별도 ADR로.

## Consequences

### Positive
- 엣지-우선 규율 보전 — "게이트 미달 전략 라이브 금지"에 예외 없음.
- 정정된 방법론(웜업+max-hold 명시)이 표준화되어 이후 모든 전략 비교의 신뢰 기반 확보.

### Negative
- 재설계 통과까지 국장 알림 공백.
- 기존 KR probe 데이터 전부 재실행 필요 (정정 조건 미적용 상태였음).

### Risks
- 재설계도 게이트를 통과하지 못할 수 있음 — KR 대형주에서 정정 조건 기준 엣지 자체가 얇을 가능성. 그 경우 국장 기능은 알림 없이 대기 상태 유지(코인 쪽 작업으로 전환).
