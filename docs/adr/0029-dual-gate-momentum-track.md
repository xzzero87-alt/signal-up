# ADR-0029: 이원 게이트 채택 + 모멘텀(선택) 트랙 개시 — point-in-time 유니버스를 검증 조건으로

**Date**: 2026-07-09
**Status**: accepted
**Deciders**: xzzero87

## Context

ADR-0028 회고에서 제품 목표를 "장기 복리 수익 극대화"로 재확인했다. 기존 6종 전멸은 전부 "개별 종목 타이밍" 계열이었고, "무엇을 살까(선택)" 축은 미탐색이었다. Cowork가 자율 수행한 Round 1 스크리닝(43종 일봉, 2022-03~2025-12, 2026년 OOS 봉인, 후보 사전 등록): 12-1 횡단면 모멘텀 top10(M2)이 표면상 압도적(누적 +142.9% vs EW B&H +64.4%, 샤프 1.06, 4/4년 벤치 이상, 비용 3배에도 강건)이었으나, **강건성 체크에서 엣지의 대부분이 2023 폭등주 3종(에코프로·에코프로비엠·알테오젠)에 집중**된 것으로 드러났다 — 3종 제외+현실 비용 시 +40.1% vs 벤치 +44.4%로 역전. 현 유니버스는 2026년 시점에 선정된 것이라 생존편향이 내재한다. 방어 트랙의 지수 타이밍(EW 200일 SMA)은 참여 비용 과다(2023: +4.4% vs +27.2%)로 미달.

## Decision

1. **게이트를 이원화한다.**
   - **Track 1 (공격)**: 기존 ADR-0022 기준 유지 — 누적 > B&H + 샤프 > 0 + 과반 구간 양(+) + 표본 충분. 포트폴리오형(선택) 전략은 포트폴리오 레벨로 판정.
   - **Track 2 (방어)**: 샤프 > B&H 샤프, 하락 구간 B&H 대비 +5%p 이상, 상승 구간 열위 −10%p 이내, MDD < B&H×0.6, 과반 구간 유지. 수치는 본 ADR로 확정.
2. **모멘텀(선택) 트랙을 계속 진행하되, point-in-time 유니버스 검증을 통과 전제 조건으로 한다.** 현 43종(2026년 선정)으로는 생존편향 때문에 판정 불가("보류"). 과거 시점 KOSPI200/시총 상위 구성으로 유니버스를 재구성해 재실행하기 전까지 채택 금지.
3. **지수 타이밍(단독 방어 오버레이)은 기각한다.** 참여 비용이 방어 이득을 압도.
4. **OOS 규율 유지**: 2026년 데이터는 파이널리스트 확정 전 개봉 금지. Round 1에서는 미개봉.
5. Cowork 자율 스크리닝 체계(사전 등록 → 샌드박스 실행 → 강건성 체크 → 보고)를 표준 절차로 채택한다. 채택 후보는 사용자 환경 CLI 패리티 재검증 필수.

## Alternatives Considered

### Alternative 1: M2 모멘텀을 현 결과로 즉시 채택
- **Pros**: 표면 수치 압도적, 비용 강건.
- **Why not**: 근거가 3종목에 집중 + 유니버스 생존편향 미통제. ADR-0024의 교훈(부풀려진 백테스트 근거로 라이브 전환) 반복 금지.

### Alternative 2: 모멘텀 트랙 폐기
- **Why not**: 풀 유니버스 4/4년 벤치 이상·문헌 근거(KR 대형주 모멘텀)·비용 강건성은 실재 — 검증 데이터 문제이지 전략 기각 근거가 아님. 판정을 "보류"로 두고 데이터를 고치는 것이 맞다.

## Consequences

### Positive
- "최대 수익" 목표와 정합하는 공격 트랙이 데이터 근거를 갖고 열림.
- 생존편향이라는 백테스트 인프라의 구조적 결함이 명시화됨 — 이후 모든 유니버스 기반 검증의 품질 기준 상승.

### Negative
- point-in-time 유니버스 데이터(과거 KOSPI200 구성 이력) 확보 작업이 선행 필요 — 새 데이터 파이프라인.

### Risks
- 과거 구성 이력을 못 구하면 모멘텀 트랙이 장기 보류됨 — 차선책(시총 프록시: 당시 거래대금 상위 N 재구성)을 함께 검토.
