# ADR-0025: 국장 일봉 v1 레짐 필터(200일 SMA) NO-GO — F0 기준선 게이트 미달 발견

**Date**: 2026-07-08
**Status**: accepted
**Deciders**: xzzero87

## Context

ADR-0024 Risks 절에서 v1 평균회귀의 약점(추세장 손실)에 대한 완화책으로 200일 SMA 레짐 필터를 후속 과제로 제시했다. 필터 방향(상회/하회 시 매수 허용)은 이론으로 정하지 않고 둘 다 43종 매트릭스(FULL+연도분할, 비용 반영, max-hold 10)로 검증했다: F1=`above_sma`, F2=`below_sma`, baseline=F0(현행 필터 없는 v1).

실험 중 두 가지 방법론 문제를 발견해 수정했다:
1. **SMA 웜업 부재**: 국장 백테스트 CLI는 `--from`~`--to` 밖의 선행 데이터를 전략에 공급하지 않아, 연도 분할 실행 시 매 구간 초반 ~200봉의 매수가 억제됐다. `BacktestEngine.warmup_bars` + `signal backtest --warmup-days`를 추가해(기본값 0, 기존 동작 불변) 선행 데이터는 지표 계산에만 쓰고 거래·지표 집계는 `--from~--to`만 대상으로 하도록 고쳤다.
2. **매트릭스 실행 신뢰성**: 43종×5구간×2필터(430회) `signal backtest` 서브프로세스 호출 방식(`kr_strategy_matrix.ps1`)이 이 실행 환경에서 중간에 조용히 종료되는 문제가 있어, 동일 `BacktestEngine`/`BbCciStrategy` 코드를 재사용하는 인프로세스 드라이버로 전환했다(CLI와 1:1 대조로 결과 일치 확인).

## Decision

1. **레짐 필터(above_sma·below_sma) 모두 NO-GO.** baseline(F0) 대비 강세년(2023·2025) 누적 중앙값 개선을 어느 쪽도 달성하지 못했다.

   | 지표 | F0(무필터) | F1(above_sma) | F2(below_sma) |
   |---|---|---|---|
   | 집계 거래수 | 883 | 247 | 654 |
   | 샤프 중앙값 | 0.30 | 0.10 | 0.27 |
   | 누적 중앙값(FULL) vs B&H | +11.51% vs +23.61% | +1.64% vs +23.61% | +10.31% vs +23.61% |
   | 강건성(양(+) 연도) | 3/4 | 0/4 | 3/4 |
   | 2022 / 2023 / 2024 / 2025 중앙값 | −8.7% / +4.2% / +5.0% / +5.0% | 0.0% / 0.0% / 0.0% / 0.0% | −2.5% / +4.2% / +4.0% / +2.4% |

   - F1: 강세년 2023(0.0% vs 4.2%)·2025(0.0% vs 5.0%) 모두 악화 + 게이트 자체도 미달(강건성 0/4).
   - F2: 강세년 2023 동률(개선 아님)·2025 악화(2.4% vs 5.0%) → 기준 2 미충족.

   `BbCciStrategy.regime_filter`/`regime_sma_period` 코드와 테스트(`tests/unit/test_bb_cci_regime.py`)는 남기되 기본값 `None`(라이브 영향 0)을 유지하고, 라이브 `.env`에는 설정하지 않는다.

2. **F0(무필터 v1) 기준선도 웜업·연도분할을 정확히 적용하면 ADR-0022 게이트를 통과하지 못한다** — 누적 중앙값 +11.51% vs B&H 중앙값 +23.61%(미달), 강건성만 3/4으로 충족. ADR-0024가 보고한 "+25.8% vs +23.6% 통과"와 다르다. 원인은 구 probe의 웜업·max-hold·연도분할 처리 차이로 추정되나 미확정이다. 본 ADR은 이 발견을 **기록만** 하며, 재검증하지 않는다.

3. **라이브 국장 v1(현행, 필터 없음)은 변경하지 않는다.** 이 실험의 스코프는 레짐 필터 채택 여부였고 NO-GO로 확정됐다. F0 게이트 미달 발견에 대한 대응(ADR-0024 재검토 여부)은 **별도 후속 과제**로 남긴다.

## Alternatives Considered

### Alternative 1: below_sma만 부분 채택
- **Pros**: above_sma보다 표본·강건성이 낫다(654 거래, 3/4 연도 양(+)).
- **Cons**: 기준 2(강세년 개선)도, 게이트 자체(누적>B&H)도 미달.
- **Why not**: 채택 기준(3개 모두 충족)을 명시적으로 충족 못함 — 상대적으로 나은 지표만으로 채택하면 사후 확증 편향.

### Alternative 2: F0 게이트 미달을 이유로 즉시 v1 재설계 착수
- **Pros**: 근본 문제를 바로 다룸.
- **Cons**: 원인(웜업 방법론 차이 vs 실제 엣지 소실)이 미확정 상태에서 성급한 재설계는 낭비.
- **Why not**: 스코프 아웃 — 이 ADR은 레짐 필터 실험 결과만 다룬다. 사용자 결정으로 별도 후속 과제로 분리.

## Consequences

### Positive
- 레짐 필터 두 방향 모두 체계적으로 검증, 재현 가능한 인프로세스 드라이버 확보.
- `warmup_bars`/`--warmup-days`는 향후 모든 KR 연도분할 백테스트(다른 필터·전략 실험 포함)에 재사용 가능한 인프라 개선.

### Negative
- F0 게이트 미달 발견으로 현재 라이브 v1의 엣지 근거(ADR-0024)에 대한 신뢰도가 흔들림 — 별도 재검토 전까지 미해결.
- `regime_filter`/`regime_sma_period` 코드는 라이브에 쓰이지 않는 경로로 남는다(기본값 None으로 영향 0, 정리 시점은 추후 검토).

### Risks
- ADR-0024 재검토를 미루면 라이브 v1이 실제로는 엣지가 불확실한 상태로 계속 운용될 위험 — 우선순위 있는 후속 과제로 권고.
- 373220(LG에너지솔루션)·259960(크래프톤) 2종은 KIS API 웜업 데이터 수신 실패/부분수신으로 FULL·2022 구간 결과가 다소 보수적일 수 있음 — 43종 중 2종, 결론(NO-GO)에 영향 없는 수준.
