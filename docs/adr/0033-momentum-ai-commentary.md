# ADR-0033: M2 월간 알림 AI 해설 — LLM은 시그널 생성 금지, 해설 전용

**Date**: 2026-07-13
**Status**: proposed
**Deciders**: 프로젝트 오너

## Context

"LLM이 사람처럼 판단해 매수·매도 시그널을 내는" 방안을 검토했으나 기각했다:
(1) point-in-time LLM이 없어 백테스트가 불가능(과거 구간 평가는 예측이 아니라 기억) —
사전 등록·봉인 OOS·게이트 규율(ADR-0029)을 적용할 방법 자체가 없음.
(2) 동일 입력에 비결정적 출력 + 모델 버전 변경 시 전략이 통째로 바뀜 — 재현 불가.
(3) 재량 판단은 본질적으로 타이밍이며, KR 타이밍은 R4~6 누적 1,784샘플 통과 0으로 종결.
대신 검증된 규칙(M2)이 시그널을 만들고, LLM은 그 결과에 맥락 해설만 붙인다.
인프라는 ADR-0020(코인 시그널 enrichment, accepted)이 이미 확립한 패턴을 재사용한다.

## Decision

1. **LLM은 시그널 경로에 개입 금지.** 종목 선정·diff·상태 영속화는 M2 규칙 그대로.
   해설은 알림 발송 **성공 후** fire-and-forget 후속 메시지 — 실패·타임아웃이 리밸런스
   알림을 지연·차단·변경하는 일은 절대 없다 (ADR-0020 §2 패턴 동일).
2. **범위**: M2 월간 리밸런스 알림(월 1회). `AiEnrichmentService`에 모멘텀 전용 메서드를
   추가하고 `MomentumJob`에 선택 주입한다. 신규 서비스·의존성 없음.
3. **해설 내용 가드레일** (시스템 프롬프트 고정): 편입 종목 관련 최근 뉴스·테마 요약
   (web_search, 출처 도메인 표기), top10 쏠림·과열에 대한 사실 기반 관찰.
   매수·매도 권유, 확률, 목표가 금지 (ADR-0002 정합). 고정 문구
   "정보 제공 목적, 투자 판단 아님" 첨부.
4. **설정 재사용**: `ai_enrichment_enabled` + `anthropic_api_key` 등 ADR-0020 필드 그대로.
   신규 설정·GUI 변경 없음. 일일 cap 공유(모멘텀은 월 1회라 영향 미미).
5. **dry_run·수동 실행 시 해설 미발송** — 알림이 실제 발송된 경우에만.

## Consequences

- (+) 규율 무손상: 게이트·봉인 OOS 체계가 해설의 존재와 무관하게 유지된다.
- (+) 구현 최소: 기존 서비스 1메서드 + 잡 조립 3곳 주입.
- (−) 해설 품질은 검증 대상이 아님 — 사실 오류 가능성은 출처 표기·권유 금지로 완화만 한다.
- (−) coin enrichment와 flag 공유: 코인 재개 시 개별 토글이 필요하면 그때 분리(YAGNI).
