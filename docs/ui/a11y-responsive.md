## 2. 개선 권고 (우선순위순)

디자인 전면 개편은 비목표(PRD §3)이므로, **의미·색감을 유지한 채 명도만 조정**하는 최소 수정안:

1. **(높음) 라이트 모드 `--color-strong` 텍스트** — `#f5a623`은 흰 배경에서 1.9:1. 라이트 오버라이드에 `--color-strong: #b87400` 추가 (≈4.6:1). 배지 배경색은 유지 가능.
2. **(높음) 라이트 모드 `--color-success` 텍스트** — 라이트 오버라이드에 `--color-success: #15803d` 추가 (≈4.5:1). `btn-start` 흰 글자도 함께 해결됨.
3. **(중간) `--color-muted-2`를 본문 텍스트로 쓰지 않기** — 12px 이하 라벨(`sum-label`, `th`, 시각)에 사용 중. 규칙: muted-2는 "장식·비필수 라벨 전용", 읽어야 하는 정보는 muted 이상.
4. **(낮음) 다크 `--color-primary` 본문 사용 주의** — 브랜드·링크 강조(굵은 글씨)는 3.0 이상이라 허용. 일반 본문 크기 파랑 텍스트는 지양.
5. **(낮음) `dir-buy`/`dir-sell` 배지** — 11px 굵은 글씨 + 자체 배경이라 실사용 대비는 표보다 양호. 현 수준 유지, 배지 폰트를 11px 미만으로 줄이지 말 것.

## 3. 접근성 체크리스트 (UI 변경 시)

- [ ] 새 텍스트 색상은 위 표에서 4.5:1(본문) / 3.0:1(18px+ 또는 14px+ 굵게) 이상인 조합인가
- [ ] `:focus-visible` 아웃라인이 보이는가 (전역 규칙 있음 — 제거 금지)
- [ ] `@media (prefers-reduced-motion: reduce)` 전역 규칙 유지 (있음)
- [ ] 클릭 대상이 버튼/링크 시맨틱인가 (`div onclick` 지양 — 현재 아코디언 헤더가 div: 키보드 접근 안 됨 → `tabindex="0"` + Enter 키 처리 또는 `<button>` 전환 권장)
- [ ] 아이콘만 있는 버튼에 `aria-label` (테마 토글에 있음 — 새 버튼도 동일하게)
- [ ] 색상만으로 의미 전달 금지 — 매수/매도는 색+텍스트(▲▼·매수/매도) 병기 (현재 준수)
- [ ] 입력 필드에 `<label for>` 연결 (현재 준수 — 유지)

## 4. 반응형 기준

현재 레이아웃은 데스크톱 우선(사이드바 184px 고정 + 테이블). 로컬 도구 특성상 모바일은 2차 우선순위지만, 최소 기준:

| 폭 | 기준 |
|----|------|
| ≥ 1024px | 표준. 사이드바 + 메인 |
| 768~1023px | 사이드바 유지하되 메인 테이블 가로 스크롤 허용 (`table-layout: fixed` 유지) |
| < 768px | (목표) 사이드바를 상단 햄버거/하단 탭으로 접기. 현재 미구현 — 구현 전까지 "가로 스크롤로 깨지지 않음"만 보장 |

체크: 좁은 화면에서 (a) 가로 스크롤이 페이지 전체가 아닌 테이블 래퍼(`.tbl-wrap`)에서만 발생, (b) 설정 폼 `input-wide`(400px)가 화면을 밀어내지 않게 `max-width: 100%` 보장.

## 5. 스크린샷 회귀 (선택 도구)

`scripts/ui_snapshot.py` — 로컬에서 서버 실행 후:

```bash
# 1) 기준 캡처 (변경 전)
python scripts/ui_snapshot.py capture --tag before

# 2) UI 변경 작업

# 3) 비교 캡처 + 차이 확인
python scripts/ui_snapshot.py capture --tag after
python scripts/ui_snapshot.py diff before after
```

Playwright 필요(개발 머신 전용, 프로젝트 의존성에 추가하지 않음): `pip install playwright && playwright install chromium`.
다크/라이트 × 주요 5페이지 + `/_styleguide`를 캡처한다. 픽셀 diff가 임계 이상이면 목록 출력 — 의도한 변경인지 눈으로 확인하는 용도다 (자동 차단 아님).
